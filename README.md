# DecodeLabs-Internship

This repository contains the projects that I completed during my DecodeLabs Internship. Each project helped me improve my Python programming and understand the basics of Artificial Intelligence and Machine Learning.

## Projects

### Project 1 - Rule-Based AI Chatbot

This is a simple chatbot made using Python. It replies to basic questions like greetings, asking its name, and other predefined messages using if-else statements.

**Skills Learned**
- Python Basics
- If-Else Statements
- While Loop
- User Input Handling

---

### Project 2 - Heart Disease Prediction

This project uses a Decision Tree model to predict whether a person has heart disease based on a dataset. It also shows the accuracy of the trained model.

**Skills Learned**
- Python
- Pandas
- Scikit-learn
- Machine Learning Basics

---

### Project 3 - AI Recommendation System

This project recommends different items based on the category selected by the user. It includes recommendations for technology, sports, music, movies, and books.

**Skills Learned**
- Python
- Dictionaries
- Loops
- Conditional Statements
