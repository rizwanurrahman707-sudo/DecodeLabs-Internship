# DecodeLabs-Internship

This repository contains the projects that I completed during my DecodeLabs Internship. Each project helped me improve my Python programming and understand the basics of Artificial Intelligence and Machine Learning.

## Projects

### Project 1 - Rule-Based AI Chatbot

This is a simple chatbot made using Python. It replies to basic questions like greetings, asking its name, and other predefined messages using if-else statements.

**Skills Learned**

* Python Basics
* If-Else Statements
* While Loop
* User Input Handling

### Project 2 - Heart Disease Prediction

This project uses a Decision Tree model to predict whether a person has heart disease based on a dataset. It also shows the accuracy of the trained model.

**Skills Learned**

* Python
* Pandas
* Scikit-learn
* Machine Learning Basics

### Project 3 - AI Recommendation System

This project recommends different items based on the category selected by the user. It includes recommendations for technology, sports, music, movies, and books.

**Skills Learned**

* Python
* Dictionaries
* Loops
* Conditional Statements

### Project 4 - Optical Character Recognition (OCR)

This project uses Optical Character Recognition (OCR) to recognize and extract text from an image. The image is pre-processed using OpenCV and then processed with Tesseract OCR. The project also checks the recognition confidence, with an 80% minimum confidence threshold.

**Skills Learned**

* Python
* OpenCV
* Pytesseract
* Image Pre-processing
* Optical Character Recognition (OCR)
* Confidence Checking

## How to Run

Install Python 3.

Install the required libraries for Project 2:

```bash
pip install pandas scikit-learn
```

For Project 4, install OpenCV and Pytesseract:

```bash
pip install opencv-python pytesseract Pillow
```

Run any project:

```bash
python Project1.py
python Project02.py
python Project3.py
python project4.py
```
